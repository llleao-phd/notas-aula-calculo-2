\chapter{Derivadas parciais}

Sejam \(f:D_f\subset\R^2 \to \R\) e \((x_0,y_0)\in D_f\). Fixado \(y=y_0\), podemos considerar a função de uma variável \(g(x) = f(x,y_0)\). Assim
\begin{definition}
    Se \(g'(x_0)\) existe, então \[\frac{\partial f}{\partial x} f(x_0,y_0) = g'(x_0)\] é a derivada parcial de \(f\) em relação a \(x\) no ponto \((x_0,y_0)\). \index{Derivada parcial}
\end{definition}

Note que \[\frac{\partial f}{\partial x} (x_0,y_0) = g'(x_0) = \lim_{x\to x_0} \frac{g(x) - g(x_0)}{x-x_0} = \lim_{x\to x_0} \frac{f(x,y_0) - f(x_0,y_0)}{x-x_0} = \lim_{h\to 0} \frac{f(x_0 + h,y_0) - f(x_0,y_0)}{h}.\]

    Dessa forma, \(\frac{\partial f}{\partial x}(x_0,y_0) = g'(x_0)\) é o coeficiente angular da reta tangente \(T\) à curva \(C\) no ponto \((x_0,y_0,f(x_0,y_0))\). Ou seja, \[\frac{\partial f}{\partial x}(x_0,y_0) = \tan(\alpha).\]

    Seja \(A\subset D_f\) o conjunto dos pontos \((x,y)\) tais que \(\frac{\partial f}{\partial x}(x,y)\) existe. Assim, fica bem definida uma função \(\frac{\partial f}{\partial x} : A \subset \R^2 \to \R\) dada por \[\frac{\partial f}{\partial x}(x,y) = \lim_{h\to 0} \frac{f(x+h,y) - f(x,y)}{h}.\] Chamamos tal função de \textbf{derivada parcial} (de 1ª ordem) de \(f\) em relação a \(x\). 
    
    De forma análoga definimos a derivada parcial de \(f\) em relação a \(y\) no ponto \(x_0,y\):
        \begin{itemize}
            \item Fixamos \(x = x_0\);
            \item tomamos \(h(y) = f(x_0,y)\);
            \item definimos \[\frac{\partial f}{\partial y}(x_0,y_0) = h'(y_0) = \lim_{y\to y_0} \frac{h(y) - h(y_0)}{y-y_0} = \lim_{y\to y_0} \frac{f(x_0,y) - f(x_0,y_0)}{y-y_0} = \lim_{h\to 0} \frac{f(x_0,y_0 + h) - f(x_0,y_0)}{h}. \]
        \end{itemize}

\begin{exercise}
    Faça a interpretação geométrica da derivada parcial em relação a \(y\).
\end{exercise}

\begin{remark}
    \begin{itemize}
        \item \(\frac{\partial f}{\partial x}(x,y)\) é a derivada em relação a \(x\) de \(f(x,y)\) olhando \(y\) constante. Analogamente, \(\frac{\partial f}{\partial y}(x,y)\) é a derivada parcial em relação a \(y\) de \(f(x,y)\) olhando \(x\) constante.
        \item Às vezes denotamos \[f_x(x_0,y_0) = \frac{\partial f}{\partial x}(x_0,y_0) = \partial_x f(x_0,y_0).\]
    \end{itemize}
\end{remark}

\begin{example}
    Considere \(f(x,y) = 2xy - 4y\). Então \[\partial_x f(x,y) = \lim_{h\to 0} \frac{f(x+h,y) - f(x,y)}{h} = \lim_{h\to 0} \frac{2(x+h) - 4y - (2xy - 4y)}{h} = \lim_{h\to 0}\frac{2hy}{h} = \lim_{h\to 0} 2y = 2y, \] e \[\partial_y f(x,y) = \partial_y (2xy - 4y) = 2x - 4.\]
\end{example}

\begin{example}
    Seja \(f(x,y) = x^3 + x^2y^3 -2y^2\). Encontre \(\partial_xf(2,1)\) e \(\partial_yf(2,1)\).

    Temos que
        \begin{itemize}
            \item \(\partial_x(x,y) = 3x^2 + 2xy^3 \Rightarrow \partial_x(2,1) = 3\cdot2^2 + 2\cdot2\cdot1^3 = 16.\)
            \item \(\partial_yf(x,y) = 3x^2y^2 - 4y \Rightarrow \partial_yf(2,1) = 3\cdot2^2\cdot1^2 - 4\cdot1 = 8.\)
        \end{itemize}
\end{example}

\end{example}

\begin{example}
    Dada \(f(x,y) = \arctan(x^2 + y^2)\), calcule \(\partial_xf(1,1)\) e \(\partial_yf(0,0)\).

    Temos \[\partial_xf(x,y) = \frac{1}{1+(x^2+y^2)^2}\cdot 2x = \frac{2x}{1+(x^2+y^2)^2}\] e \[\partial_yf(x,y) = \frac{1}{1+(x^2+y^2)^2}2y = \frac{2y}{1+(x^2+y^2)^2}\] portanto \[\partial_xf(1,1) = \frac{2}{1+(1+1)^2} = \frac{2}{5} \text{ e } \partial_yf(0,0) = \frac{0}{1} = 0.\]
\end{example}

\begin{example}
    Seja \(f(x,y) = 4 - x^2 - 2y^2\). Encontre as derivadas parciais de \(f\) e faça a interpretação geométrica de \(\frac{\partial f}{\partial x}(1,1)\) e \(\frac{\partial f}{\partial y}(1,1).\)

    É claro que \(D_f = \R^2\) e \[\operatorname{Im}_f = \{z = f(x,y) : (x,y)\in D_f\} = \{z = 4-x^2 - y^2 : (x,y)\in\R^2\} = (-\infty,4].\] Além disso \(\frac{\partial f}{\partial x}(x,y) = -2x\), \(\frac{\partial f}{\partial y}(x,y) = -4y\) e \(\frac{\partial f}{\partial x}(1,1) = -2\).

    Para a interpretação geométrica de \(\partial_xf(1,1)\) e \(\partial_yf(1,1)\), faremos o esboço do gráfico de \(f\).

    Para esboçar o gráfico de \(f\), note que se \(x = 0\), então \(z = 4 - y^2\) é uma parábola no plano yz, e se \(y = 0\), \(z = 4 - x^2\) é uma parábola no plano xz. Além disso, para \(k\leq 4\) temos
        \begin{align*}
            x^2 + y^2 = 4-k
                & \Leftrightarrow \frac{x^2}{4-k} + \frac{2y^2}{4-k} = 1 \\
                & \Leftrightarrow \frac{x^2}{4-k} + \frac{y^2}{\left( \frac{4-k}{2} \right)} = 1 \\
                & \Leftrightarrow \frac{x^2}{(\sqrt{2-k})^2} + \frac{y^2}{\left( \frac{\sqrt{4-k}}{\sqrt{2}} \right)^2} = 1,
        \end{align*}
    portanto as curvas de nível de \(f\) são elipses concêntricas.

\begin{example}
    Estude as derivadas parciais de \(f(x,y) = \begin{cases}
        \frac{x^3 - y^2}{x^2 + y^2},\; (x,y)\neq(0,0) \\
        0,\; (x,y)=(0,0).
    \end{cases}\) 

    Vamos começar estudando \(\frac{\partial f}{\partial x}\)
        \begin{itemize}
            \item Se \((x,y) \neq (0,0)\), temos \[\partial_xf(x,y) = \frac{3x^2(x^2+y^2) - (x^3-y^2)2x}{(x^2+y^2)^2}.\]
            \item Se \((x,y)=(0,0)\), \[\partial_xf(0,0) = \lim_{x\to 0} \frac{f(x,0)-f(0,0)}{x-0} = \lim_{x\to 0} \frac{x}{x} = \lim_{t\to 0} 1 = 1.\]
        \end{itemize}
    Portanto \[\frac{\partial f}{\partial x}(x,y) = \begin{cases}
        \frac{x^4 + 3x^2y^2 + 2xy^2}{(x^2+y^2)^2},\; (x,y)\neq(0,0) \\
        1,\; (x,y)=(0,0)
    \end{cases}\]

    Agora, para \(\frac{\partial f}{\partial y}\),
    \begin{itemize}
        \item Se \((x,y)\neq(0,0)\), \[\partial_yf(x,y) = \frac{-2y(x^2+y^2)-(x^3-y^2)2y}{(x^2+y^2)^2} = \frac{-2x^2y - 2x^3y}{(x^2+y^2)^2},\]
        \item se \((x,y)=(0,0)\), \[\partial_yf(0,0) = \lim_{y\to 0} \frac{f(0,y)-f(0,0)}{y} = \lim_{y\to 0} -\frac{1}{y} = -\infty.\]
    \end{itemize}
    Portanto \(\partial_y f(x,y)\) está definida apenas para \((x,y)\neq(0,0)\).
\end{example}

\begin{proposition}
    Seja \(f:\R^2\to\R\) tal que \(\frac{\partial f}{\partial x}(x,y) = 0\), para todo \((x,y)\in\R^2\). Então \(f\) não depende de \(x\), ou seja, existe \(\phi:\R\to\R\) tal que \(f(x,y) = \phi(y),\) para todo \((x,y)\in\R 2\).
\end{proposition}

\begin{proof}
    Fixado \(y_0\in\R\), considere a função \[h(x) = f(x,y_0),\; x\in\R.\] Então \[h'(x) = \partial_xf(x,y_0) = 0\,; \forall x\in\R,\] ou seja, \(h\) é contínua (dado que é diferenciável) e \(h'(x) = 0\), para todo \(x\in\R\). Segue então que \(h\) é constante em \(\R\). Portanto \[h(x) = h(0),\;\forall x\in\R,\] daí \[f(x,y_0) = f(0,y_0),\;\forall x\in\R.\] Como \(y_0\in\R\) é arbitrário, segue que \[f(x,y) = f(0,y),\; \forall(x,y)\in\R^2.\] Tomando \(\phi(y) = f(0,y)\) temos que \[f(x,y) = \phi(y),\; \forall(x,y)\in\R^2.\]
\end{proof}

\section{Derivadas de funções definidas implicitamente}

Dada a equação \[z = \sqrt{1 - x^2 - y^2},\; x^2 + y^2 < 1\] dizemos que \(z\) é uma \textbf{função explícita} de \((x,y)\), pois podemos escrever \(z = f(x,y)\), com \(f(x,y) = \sqrt{1 - x^2 - y^2}\) e \(D_f = \{(x,y)\in\R^2 : x^2 + y^2 < 1\}\).

No entanto, a equação
\begin{equation}\label{eq.esfera}
    x^2 + y^2 + z^2 - 1 = 0,\; z>0
\end{equation}
define a mesma função \(f\), uma vez que isolando \(z\) em função de \(x\) e \(y\) temos \[z^2 = 1 - x^2 - y^2 \Rightarrow z = \sqrt{1-x^2-y^2},\; x^2 + y^2 < 1.\] Neste caso dizemos que \(z = f(x,y)\) está definida \textbf{implicitamente} pela equação \eqref{eq.esfera}.

\begin{remark}
    Note que considerando \(g(x,y,z) = x^2 + y^2 + z^2 -1\) e \(f(x,y) = \sqrt{1-x^2-y^2}\), com \(x^2 + y^2 < 1\), e substituindo \(z = f(x,y)\), com \((x,y)\in D_f\), em \(g(x,y,z)\) obtemos \[g(x,y,f(x,y)) = x^2 + y^2 + (\sqrt{1-x^2-y^2})^2 - 1 = x^2 + y^2 + 1 - x^2 - y^2 - 1 = 0.\] Ou seja, \((x,y,f(x,y))\) satisfaz a equação \[g(x,y,z) = 0.\]

    Esta é uma característica de toda função definida implicitamente por uma equação nas variáveis \(x, y\) e \(z\). Logo, em geral, temos a seguinte caracterização:
\end{remark}

\begin{definition}
    Uma função \(z = f(x,y)\) é \textbf{definida implicitamente} pela equação \(g(x,y,z) = 0\) se, para todo \((x,y)\in D_f\), \(g(x,y,f(x,y)) = 0.\)
\end{definition}

\begin{remark}
    É importante notar que:
        \begin{enumerate}
            \item Nem toda função \(z = f(x,y)\) definida implicitamente por uma equação \(g(x,y,f(x,y)) = 0\) pode ser colocada de maneira explícita. Portanto a caracterização acima é importante.
            \item A caracterização acima implica que o gráfico da função implícita coincide com \textit{uma parte do} (ou todo o) gráfico da equação.
        \end{enumerate}
\end{remark}

\begin{exercise}
    Verifique que as funções
        \begin{align*}
            z & = \sqrt{1-x^2-y^2},\; x^2 + y^2 \leq 1 \\
            z & = - \sqrt{1-x^2-y^2},\; x^2 + y^2 \leq 1
        \end{align*}
também são definidas pela equação \[x^2 + y^2 + z^2 - 1 = 0.\]
\end{exercise}

\begin{example}
    Seja \(z = f(x,y)\) dada implicitamente por \[x^2 + y^2 + z^2 = 1.\] Calcule \(\frac{\partial z}{\partial x}\) e \(\frac{\partial z}{\partial y}\).

    Para calcular \(\frac{\partial z}{\partial x}\) notamos que isolando \(z\) na equação dada obtemos \[z = \sqrt{1 - x^2 - y^2},\; x^2 + y^2 < 1,\] logo \[\frac{\partial z}{\partial x} = \frac{\partial}{\partial x} \sqrt{1-x^2-y^2} = \frac{1}{2}(1-x^2-y^2)^\frac{1}{2}\cdot(2x) = -\frac{x}{\sqrt{1-x^2-y^2}},\] ou seja, \[\frac{\partial z}{\partial x} = - \frac{x}{\sqrt{1-x^2-y^2}},\; x^2 + y^2 < 1.\]

    Podemos também calcular \(\frac{\partial z}{\partial x}\) trabalhando diretamente com a equação dada. Neste caso
        \begin{align*}
            \frac{\partial}{\partial x} (x^2 + y^2 + z^2) = \frac{\partial}{\partial x}(1)
            \Rightarrow & \frac{\partial}{\partial x} (x^2 + y^2) + \frac{\partial}{\partial x} z^2 = 0 \\
            \Rightarrow & 2x + \frac{d}{dz}z^2\cdot\frac{\partial z}{\partial x} = 0 \\
            \Rightarrow & 2x + 2z\cdot\frac{\partial z}{\partial x} = 0 \\
            \Rightarrow & \frac{\partial z}{\partial x} = -\frac{x}{z} = \frac{-x}{\sqrt{1-x^2-y^2}},; x^2 + y^2 < 1.
        \end{align*}

    Vamos agora calcular \(\frac{\partial z}{\partial y}\).
        \begin{align*}
            \frac{\partial}{\partial y} (x^2 + y^2 + z^2) = \frac{\partial}{\partial y}(1)
                & \Rightarrow 2y + \frac{\partial}{\partial y}(z^2) = 0 \\
                & \Rightarrow 2y + 2z \frac{\partial z}{\partial y} = 0 \\
                & \Rightarrow \frac{\partial z}{\partial y} = -\frac{y}{z} = -\frac{y}{\sqrt{1-x^2-y^2}},\; x^2 + y^2 < 1.
        \end{align*}
\end{example}

\begin{remark}
    Cuidado com as notações! \[\frac{\partial f}{\partial x} (x,y) \neq \frac{d}{dx}[f(x,y)].\]

    Por exemplo, \(\frac{\partial}{\partial x} (x^2 + y^2) = 2x\) enquanto que \(\frac{d}{dx} (x^2 + y^2) = 2x + 2y \frac{dy}{dx}\)
\end{remark}

\begin{example}
    Suponha que \(z = f(x,y)\) seja dada implicitamente pela equação \[e^{xyz} = x^2 + y^2 + z^2.\] Encontre \(\frac{\partial z}{\partial x}\) em termos de \(x, y\) e \(z\).

    Note que, neste caso, não conseguimos isolar \(z\) na equação dada. Logo devemos trabalhar diretamente com a equação. Para \((x,y)\in D_f\)
        \begin{align*}
            \frac{\partial}{\partial x} (e^{xyz}) = \frac{\partial}{\partial x} (x^2 + y^2 + z^2)
                & \Rightarrow e^{xyz} \frac{\partial}{\partial x}(xyz) = \frac{\partial}{\partial x}(x^2 + y^2) + \frac{\partial}{\partial x}(z^2) \\
                & \Rightarrow e^{xyz}\left[ \frac{\partial}{\partial x}(xy)\cdot z + xy\frac{\partial z}{\partial x} \right] = 2x + 2z \frac{\partial z}{\partial x} \\
                & \Rightarrow e^{xyz}\left[ yz + xy\frac{\partial z}{\partial x} \right] = 2z + 2z\frac{\partial z}{\partial x} \\
                & \Rightarrow \left[ e^{xyz}xy - 2z \right]\frac{\partial z}{\partial x} = 2x - e^{xyz}yz \\
                & \Rightarrow \frac{\partial z}{\partial x} = \frac{2x - e^{xyz} yz}{e^{xyz} xy - 2z},
        \end{align*}
desde que \(e^{xyz} xy - 2z \neq 0\).
\end{example}

\section{Derivadas parciais para funções de mais de duas variáveis}

As derivadas parciais também podem ser definidas para funções de três ou mais variáveis e as definições são análogas ao que fizemos para funções de duas variáveis. Por exemplo, definimos a derivada parcial em relação a \(x\) da função \(f(x,y,z)\) pondo \[\frac{\partial f}{\partial x} = \lim_{\to 0} \frac{f(x+h,y,z) - f(x,y,z)}{h}\] e esta é determinada olhando \(x\) e \(y\) como constantes e derivamos \(f(x,y,z)\) em relação a \(x\).

Mais ainda, se \(w = f(x,y,z)\), então \(\frac{\partial w}{\partial x}\) pode ser interpretada como a taxa de variação de \(w\) com relação a \(x\), quando \(y\) e \(z\) são mantidos constantes. Entretanto, não podemos interpretá-la geometricamente, já que o gráfico de \(f\) está em \(\R^4\).

Em geral, se \(u = f(x_1,x_2,\dots,x_n)\), então sua derivada parcial em relação a i-ésima variável \(x_i\) é dada por \[\frac{\partial f}{\partial x_i} = \lim_{h\to 0}\frac{f(x_1,\dots,x_i+h,\dots x_n) - f(x_1,\dots,x_i,\dots,x_n)}{h}.\]

\begin{example}
    Seja \(f(x,y,z) = xy + xz + yz.\) Determine \(\partial_x f, \partial_y f\) e \(\partial_z f\). \[\partial_x f(x,y,z) = y + z,\; \partial_y f(x,y,z) = x + z \text{ and } \partial_z f(x,y,z) = x + y.\]
\end{example}

\begin{example}
    Determine as derivadas parciais da função \(f(x,y,z) = e^{x,y,z}\). \[\partial_x f(x,y,z) = e^{xyz} yz,\; \partial_y f(x,y,z) = e^{xyz} xz \text{ and } \partial_z f(x,y,z) = e^{xyz} xy.\]
\end{example}

\section{Derivadas parciais de ordem superior}

Se \(f:D_f\subset \R^2 \to \R^2\) é uma função de duas variáveis, vimos que suas derivadas parciais \(\frac{\partial f}{\partial x} = f_x\) e \(\frac{\partial f}{\partial y} = f_y\) são \textit{funções} de duas variáveis, portanto podemos considerar suas derivadas parciais, que chamamos de derivadas parciais de segunda ordem.

Se \(z = f(x,y)\), denotamos
    \begin{enumerate}
        \item[i)] \(\frac{\partial}{\partial x} \left( \frac{\partial f}{\partial x} \right) = \frac{\partial^2 f}{\partial x^2} = \frac{\partial^2 z}{\partial x^2} = (f_x)_x = f_{xx}\).
        \item[ii)] \(\frac{\partial}{\partial y} \left( \frac{\partial f}{\partial y} \right) = \frac{\partial^2 f}{\partial y^2} = \frac{\partial^2 z}{\partial y^2} = (f_y)_y = f_{yy}\).
        \item[iii)] \(\frac{\partial}{\partial x} \left( \frac{\partial f}{\partial y} \right) = \frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 z}{\partial x \partial y} = (f_y)_x = f_{yx}\).
        \item[iv)] \(\frac{\partial}{\partial y} \left( \frac{\partial f}{\partial x} \right) = \frac{\partial^2 f}{\partial y \partial x} = \frac{\partial^2 z}{\partial y \partial x} = (f_x)_y = f_{xy}\).    
    \end{enumerate}

\begin{example}
    Seja \(f(x,y) = x^3 + x^2 y^3 - 2y^2.\) Encontre as derivadas parciais de 2º ordem de \(f\).

    Sabemos que \[\frac{\partial f}{\partial x}(x,y) = 3x^2 + 2xy^3 \text{ e } \frac{\partial f}{\partial y} = 3x^2y^2 - 4y.\] Logo \[\frac{\partial^2 f}{\partial x^2}(x,y) = 6x + 2y^3 , \quad \frac{\partial^2 f}{\partial y^2}(x,y) = 6x^2 - 4.\] \[\frac{\partial^2 f}{\partial y \partial x}(x,y) = 6xy^2, \quad \frac{\partial^2 f}{\partial x \partial y}(x,y) = 6xy^2.\]
\end{example}

Observe que no exemplo acima, \[\frac{\partial^2 f}{\partial x \partial y}(x,y) = \frac{\partial^2 F}{\partial y \partial x}(x,y).\] Então, é natural a gente perguntar se isso sempre acontece. Veremos que isso ocorre apenas em alguns casos especiais.

\begin{example}
    Considere \[f(x,y) = \begin{cases}
        \frac{xy^3}{x^2 + y^2},\; (x,y)\neq(0,0) \\
        0,\; (x,y)=(0,0)
    \end{cases}.\] Mostraremos que \(\frac{\partial^2 f}{\partial x \partial y} (0,0) \neq \frac{\partial^2 f}{\partial y \partial x}(0,0).\)

    Lembre que para encontrarmos \(\frac{\partial^2 f}{\partial x \partial y}(0,0)\), devemos primeiro encontrar a função \(\frac{\partial f}{\partial y}\). Para isso note que, se \((x,y)\neq (0,0)\), \[\frac{\partial f}{\partial y}(x,y) = \frac{3xy^2(x^2+y^2) - xy^3\cdot 2y}{(x^2 + y^2)^2} = \frac{xy^4 + 3x^3 y^2}{(x^2+y^2)^2}\] e se \((x,y) = (0,0)\), \[\frac{\partial f}{\partial y}(0,0) = \lim_{y\to 0} \frac{f(0,y) 0 f(0,0)}{y} = 0,\] portanto \[\frac{\partial}{\partial y}f(x,y) = \begin{cases}
        \frac{xy^4 + 3x^3 y^2}{(x^2+y^2)^2},\; (x,y)\neq(0,0) \\
        0,\; (x,y) = (0,0)
    \end{cases}.\] Assim \[\frac{\partial^2 f}{\partial x \partial y}(0,0) = \frac{\partial}{\partial x}\left( \frac{\partial f}{\partial y} \right)(0,0) = \lim_{x\to 0} \frac{\frac{\partial f}{\partial y}(x,0) - \frac{\partial f}{\partial y}(0,0)}{x} = 0.\]

    Usando o mesmo raciocínio (ou seja, calculando \(\frac{\partial f}{\partial x}\) e depois \(\frac{\partial^2 f}{\partial x \partial y}\)) mostramos que \(\frac{\partial^2 f}{\partial y\partial x}(0,0) = 1\), ou seja \[\frac{\partial^2 f}{\partial x \partial y}(x,y) \neq \frac{\partial^2 F}{\partial y \partial x}(x,y).\]
\end{example}

O exemplo anterior nos mostra que a igualde \(\frac{\partial^2 f}{\partial x \partial y}(x,y) = \frac{\partial^2 F}{\partial y \partial x}(x,y)\) nem sempre acontece. O próximo resultado nos diz em que condições esta propriedade acontece.

\begin{theorem}[Schwarz]
    Seja \(f:D_f\subset\R^2 \to \R^2\) com \(D_f\) aberto. Se todas as derivadas parciais de 2º ordem existem e são contínuas em \(D_f\), então \[\frac{\partial^2 f}{\partial x \partial y}(x_0,y_0) = \frac{\partial^2 F}{\partial y \partial x}(x_0,y_0),\; \forall (x_0,y_0)\in D_f.\]
\end{theorem}

\section{Funções diferenciáveis}

\textbf{Pergunta. } Será que o conceito de derivadas parciais é uma boa generalização do conceito de diferenciabilidade dado para funções de uma variável?

\begin{example}
    Considere \[f(x,y) = \begin{cases}
        \frac{xy}{x^2 + y^2},\; (x,y)\neq(0,0) \\
        0,\; (x,y)=(0,0)
    \end{cases}.\] Vamos esetudar suas derivadas parciais em \((0,0)\).

    Temos \[\partial_x f(0,0) = \lim_{x\to 0} \frac{f(x,0) - f(0,0)}{x} = 0 \text{ e } \partial_y f(0,0) = \lim_{y\to 0}\frac{f(0,y)-f(0,0)}{y} = 0.\] Portanto as derivadas parciais existem em \((0,0)\).

    Vamos estudar agora a continuidade de \(f\) em \((0,0)\). Se \(x=0\), então \[\lim_{(x,y)\to(0,0)} f(x,y) = \lim_{y\to 0} f(0,y) = 0,\] mas se \(y=x\), \[\lim_{(x,y)\to(0,0)} f(x,y) = \lim_{x\to 0} \frac{x^2}{2x^2} = \frac{1}{2},\] logo o limite não existe e, consequentemente, \(f\) não é contínua em \((0,0)\).
\end{example}

No exemplo anterior temos que as derivadas parciais existem num ponto \((x_0,y_0)\), mas a função não é contínua em \((x_0,y_0)\). Portanto a existência das derivadas parciais \textit{não} é uma boa generalização para a noção de diferenciabilidade, uma vez que diferenciabilidade deve implicar em continuidade.

Vamos ver agora como estender adequadamente o conceito de diferenciabilidade para funções de várias variáveis.

Seja \(f:D_f\subset\R \to \R\) uma função de uma variável. Se \(f\) é diferenciável em \(x_0\), então existe \(a\in\R\) (\(a = f'(x_0)\)) tal que \[\lim_{h\to 0}\frac{f(x_0 + h) - f(x_0)}{h} = a \Leftrightarrow \lim_{h\to 0} \frac{f(x_0+h) - f(x_0) - ah}{h} = 0.\]

Note que esta forma ainda não é adequada para a generalização, pois se \(f\) for uma função de duas variáveis, então \(h\) será um par ordenado, portanto a razão incremental não terá sentido.

Agora, como \[\lim_{h\to 0} \frac{G(h)}{h} = 0 \Leftrightarrow \lim_{h\to 0} \frac{G(h)}{|h|} = 0,\] temos que \[\lim_{h\to 0} \frac{f(x_0 + h) - f(x_0) - ah}{h} = 0 \Leftrightarrow \lim_{h\to 0} \frac{f(x_0+h) - f(x_0) - ah}{|h|} = 0.\] Ou seja, \[\lim_{h\to 0} \frac{f(x_0 + h) - f(x_0)}{h} = a \Leftrightarrow \lim_{h\to 0} \frac{f(x_0+h) - f(x_0) - ah}{|h|} = 0.\] Ou ainda, \(f\) é diferenciável em \(x_0\) se, e somente se, existe \(a\in\R\) tal que \[\lim_{h\to 0} \frac{f(x_0 + h)-f(x_0) - ah}{|h|} = 0.\] Neste sentido podemos generalizar a definição de diferenciabilidade, pois dividir por \(\|(h,k)\|\) faz sentido.

\begin{definition}
    Sejam \(f:A \subset \R^2 \to \R\), \(A\) aberto e \((x_0,y_0)\in A\). Dizemos que \(f\) é \textbf{diferenciável} em \((x_0,y_0)\) se existir \((a,b)\in\R^2\) tal que \[\lim_{(h,k)\to(0,0)} \frac{f(x_0 + h, y_0 + k) - f(x_0,y_0) - ah - bk}{\|(h,k)\|} = 0.\] 
\end{definition}

\begin{theorem}\label{DiferenciabilidadeImplicaContinuidade}
    Se \(f\) é diferenciável em \((x_0,y_0)\), então \(f\) é contínua em \((x_0,y_0)\).
\end{theorem}

\begin{proof}
    Como \(f\) é diferenciável em \((x_0,y_0)\), existem \(a,b\in\R\) tais que \[\lim_{(h,k)\to(0,0)} \frac{E(h,K)}{\|(h,k)\|} = 0,\] com \(E(h,k) = f(x_0 + h,y_0 + k) - f(x_0,y_0) - ah - bk.\) Logo
        \begin{equation}\tag{*}\label{lim1}
            \lim_{(h,k)\to(0,0)} E(h,k) = \lim_{(h,k)\to(0,0)} \frac{E(h,k)}{\|(h,k)\|} \|(h,k)\| = 0.
        \end{equation}
    Por outro lado,
        \begin{equation}\tag{**}\label{lim2}
            \lim_{(h,k)\to(0,0)} (ah + bk) = 0.
        \end{equation}

    Assim, segue de \eqref{lim1} e \eqref{lim2} que
        \begin{align*}
            \lim_{(x,y)\to(x_0,y_0)} f(x,y)
            & = \lim_{(h,k)\to(0,0)} f(x_0 + h,y_0+k) \\
            & = \lim_{(h,k)\to(0,0)} [E(h,k) + f(x_0,y_0) + (ah+bk)] = f(x_0,y_0).
        \end{align*}

    Do anterior, \(f\) é contínua em \((x_0,y_0)\).
\end{proof}

\begin{theorem}\label{DiferenciabilidadeImplicaDerivadasParciais}
    Sejam \(f:A\subset\R^2 \to \R\), \(A\) aberto e \((x_0,y_0)\in A\). Se \(f\) é diferenciável em \((x_0,y_0)\), então \(f\) tem derivadas parciais em \((x_0,y_0)\).
\end{theorem}

\begin{proof}
    Como \(f\) é diferenciável em \((x_0,y_0)\), sabemos que existem \(a,b\in\R\) tais que
    \begin{equation}\tag{*}\label{lim3}
        \lim_{(h,k)\to(0,0)} \frac{E(h,k)}{\|(h,k)\|} = 0,
    \end{equation}
com \(E(h,k) = f(x_0+h,y_0+k)-f(x_0,y_0) -ah - bk.\) Em particular, segue de \eqref{lim3} que
    \begin{align*}
        \lim_{(h,k)\to(0,0)} \frac{E(h,0)}{\|(h,0)\|} 
            & = \lim_{h\to 0} \frac{f(x_0+h,y_0) - f(x_0,y_0) - ah}{|h|} = 0 \\
            & \Rightarrow \lim_{h\to 0} \frac{f(x_0+h,y_0) - f(x_0,y_0) - ah}{h} = 0 \\
            & \Rightarrow \lim_{h\to 0} \frac{f(x_0+h,y_0)-f(x_0,y_0)}{h} = a,
    \end{align*}
portanto \(\frac{\partial f}{\partial x}(x_0,y_0)\) existe e \(\frac{\partial f}{\partial x}(x_0,y_0) = a\).

De forma análoga, mostramos que \(\frac{\partial f}{\partial y}(x_0,y_0)\) existe e \(\frac{\partial f}{\partial y}(x_0,y_0)  = b\).
\end{proof}

\begin{remark}
    Mostramos acima que se \(f\) é diferenciável em \((x_0,y_0)\), então \(a\) e \(b\) da definição devem ser necessariamente \[\frac{\partial f}{\partial x}(x_0,y_0) = a \text{ e } \frac{\partial f}{\partial y}(x_0,y_0)  = b.\]
\end{remark}

Segue diretamente do Teorema \ref{DiferenciabilidadeImplicaDerivadasParciais} o seguinte resultado:

\begin{corollary}
    Sejam \(f:A\subset\R^2 \to \R\), com \(A\) aberto, e \((x_0,y_0)\in A\). Então \(f\) é diferenciável em \((x_0,y_0)\) se, e somente se, \(f\) tem derivadas parciais em \((x_0,y_0)\) e \[\lim_{(h,k)\to(0,0)} \frac{f(x_0+h,y_0+k) - f(x_0,y_0) - \frac{\partial f}{\partial x}(x_0,y_0)h - \frac{\partial f}{\partial y}(x_0,y_0)k}{\|(h,k)\|} = 0.\]
\end{corollary}

\begin{remark}
    Do estudo acima, notamos que
        \begin{itemize}
            \item Para provar que \(f\) é diferenciável em \((x_0,y_0)\), basta provar que \(\frac{\partial f}{\partial x}(x_0,y_0)\) e \(\frac{\partial f}{\partial y}(x_0,y_0)\) existem e que \[\lim_{(h,k)\to(0,0)} \frac{f(x_0+h,y_0+k) - f(x_0,y_0) - \frac{\partial f}{\partial x}(x_0,y_0)h - \frac{\partial f}{\partial y}(x_0,y_0)k}{\|(h,k)\|} = 0.\]
            \item Se \(\frac{\partial f}{\partial x}(x_0,y_0)\) ou \(\frac{\partial f}{\partial y}(x_0,y_0)\) não existir, então \(f\) não será diferenciável em \((x_0,y_0)\).
            \item Se \(\frac{\partial f}{\partial x}(x_0,y_0)\) e \(\frac{\partial f}{\partial y}(x_0,y_0)\) existem, mas o limite não é zero, então \(f\) não é diferenciável.
            \item Se \(f\) não é contínua em \((x_0,y_0)\), então \(f\) não é diferenciável em \((x_0,y_0)\).
        \end{itemize}
\end{remark}

\begin{definition}
    Dizemos que \(f\) é diferenciável em \(A\subset D_f\), se \(f\) é diferenciável em todo \((x,y)\in A\). Dizemos, simplesmente, que \(f\) é diferenciável se \(f\) é diferenciável em todo \((x,y)\in D_f\).
\end{definition}

\begin{example}
    Mostre que \(f(x,y) = x^2 y\) é diferenciável.

    Temos que \[\frac{\partial f}{\partial x}(x,y) = 2xy \text{ e } \frac{\partial f}{\partial y}(x,y) = x^2.\] Logo
        \begin{align*}
            E(h,k)
                & = f(x+h,y+k) - f(x,y) - \frac{\partial f}{\partial x}(x,y) h - \frac{\partial f}{\partial y}(x,y) k \\
                & = (x+h)^2(y+k) - x^2 y - 2xyh - x^2k \\
                & = (x^2+2xh+h^2)(y+k) - x^2 y - 2xyh - x^2 k \\
                & = x^2y + 2xyh + h^2y + x^2k + 2xkh + h^2 - x^2 y - 2xyh - x^2 k \\
                & = 2xkh + h^2y + h^2 k,
        \end{align*}
    assim,
        \begin{align*}
            \lim_{(h,k)\to(0,0)} \frac{E(h,k)}{\|(h,k)\|}
                & \lim_{(h,k)\to 0} \frac{2xkh + h^2y + h^2 k}{\sqrt{h^2 + k^2}} \\
                & \lim_{(h,k)\to(0,0)} \left( 2xk\frac{h}{\sqrt{h^2 + k^2}} + yh \frac{h}{\sqrt{h^2 + k^2}} + kh \frac{h}{\sqrt{h^2 + k^2}} \right) \\
                & = \lim_{(h,k)\to(0,0)} (2xk + yh + kh)\frac{h}{\sqrt{h^2 + k^2}}.
        \end{align*}
    Agora, notando que \[|h| = \sqrt{h^2} \leq \sqrt{h^2 + k^2} \Rightarrow \frac{|h|}{\sqrt{h^2 + k^2}} \leq 1,\; \forall (h,k)\neq(0,,0),\] concluímos que \(\frac{h}{\sqrt{h^2 + k^2}}\) é uma função limitada, portanto \[\lim_{(h,k)\to(0,0)} (2xk + yh + kh)\frac{h}{\sqrt{h^2 + k^2}} = 0. \] Ou seja, \[\lim_{(h,k)\to(0,0)} \frac{E(h,k)}{\|(h,k)\|} = 0,\] ou ainda \[\lim_{(h,k)\to(0,0)} \frac{f(x_0+h,y_0+k) - f(x_0,y_0) - \frac{\partial f}{\partial x}(x,y) h - \frac{\partial f}{\partial y}(x,y) k}{\|(h,k)\|} = 0,\;\forall(x,y)\in\R^2. \] Daí podemos concluir que \(f\) é diferenciável.
\end{example}

\begin{example}
    \(f(x,y) = \begin{cases}
        \frac{xy}{x^2 + y^2},\; (x,y)\neq(0,0) \\
        0,\; (x,y)=(0,0)
    \end{cases}\) é diferenciável em \((0,0)\)?

    Já vimos que \(f\) não é contínua em \((0,0)\), portanto \(f\) não é diferenciável em \((0,0)\).
\end{example}

\begin{example}
    \(f(x,y) = \begin{cases}
        \frac{x^3}{x^2+y^2},\; (x,y)\neq(0,0) \\
        0,\; (x,y)=(0,0)
    \end{cases}\) é diferenciável em \((0,0)\)?

    Como já vimos antes, \[\lim_{(x,y)\to(0,0)} f(x,y) = \lim_{(x,y)\to(0,0)} \frac{x^3}{x^2 + y^2} = \lim_{(x,y)\to(0,0)} x \frac{x^2}{x^2+y^2} = 0,\] logo \(f\) é contínua em \((0,0)\). Além disso,
    \[\frac{\partial f}{\partial x}(0,0) = \lim_{x\to 0} \frac{f(x,0)-f(0,0)}{x} = \lim_{x\to 0} \frac{x}{x} = 1\] e \[\frac{\partial f}{\partial y}(0,0) = \lim_{y\to 0} \frac{f(0,y)-f(0,0)}{y} = 0.\] Portanto
        \begin{align*}
            E(h,k)
                & = f(0+h,0+k) - f(0,0) - \partial_x f(0,0) h - \partial_y f(0,0) k \\
                & = f(h,k) - h \\
                & = \frac{h^3}{h^2 + k^2} - h \\
                & = -\frac{hk^2}{h^2+k^2},
        \end{align*}
    assim, \[\lim_{(h,k)\to(0,0)} \frac{\left( -\frac{hk^2}{h^2+k^2} \right)}{\sqrt{h^2 + k^2}} = \lim_{(h,k)\to(0,0)} -\frac{hk^2}{h^2+k^2}\frac{1}{\sqrt{h^2+k^2}}.\] Para \(f\) ser diferenciável em \((0,0)\) devemos ter que \[\lim_{(h,k)\to(0,0)} -\frac{hk^2}{h^2+k^2}\frac{1}{\sqrt{h^2+k^2}} = 0.\] É fácil verificar que se \(h=0\) ou \(k=0\), então o limite acima é de fato \(0\). Mas, tomando \(k=h\), temos que \[\lim_{(h,k)\to(0,0)} -\frac{hk^2}{h^2+k^2}\frac{1}{\sqrt{h^2+k^2}} = \lim_{h\to 0} -\frac{h^2}{2h^2}\frac{1}{\sqrt{2h^2}} = \lim_{h\to 0} - \frac{h}{2\sqrt{2}|h|} = \begin{cases}
        \frac{-1}{2\sqrt{2}},\; \text{ se } h\to 0^+ \\
        \frac{1}{2\sqrt{2}},\; \text{ se } h\to 0^-,
    \end{cases}\] portanto o limite não existe, consequentemente, \(f\) não é diferenciável em \((0,0)\).
\end{example}

\begin{remark}
    Note que no exemplo anterior temos uma função contínua em \((0,0)\) que admite derivadas parciais em \((0,0)\), mas não é diferenciável em \((0,0)\).
\end{remark}

\textbf{Pergunta. } Existe uma maneira mais fácil de verificar a diferenciabilidade de uma função?

\begin{theorem}
    Sejam \(f:A\subset\R^2\to\R\), com \(A\) aberto, e \((x_0,y_0)\in A\). Se \(\frac{\partial f}{\partial x}\) e \(\frac{\partial f}{\partial y}\) existirem em \(A\) e forem contínuas no ponto \((x_0,y_0)\), então \(f\) é diferenciável em \((x_0,y_0)\).
\end{theorem}
\textbf{Prova. } \cite{guidorizzi}[pg. 195]

Muitas vezes é mais fácil verificar a continuidade das derivadas parciais do que a diferenciabilidade pela definição. Dessa forma, o resultado anterior é importante e simplifica o trabalho de verificar a diferenciabilidade de uma função.

\begin{example}
    Considere a função \(f(x,y) = x^2 y\) novamente. Temos que \(D_f = \R^2\) e \[\partial_x f(x,y) = 2xy \text{ e } \partial_y f(x,y) = x^2,\] como ambas as derivadas parciais são contínuas em \(\R^2\), concluímos que \(f\) é diferenciável.
\end{example}

\begin{example}
    Estude a diferenciabilidade da função \(f(x,y) = \sin(x^2 + y^2)\) em \(\R^2\).

    Temos que \(f\) está definida em \(\R^2\) e \[\partial_x f(x,y) = 2x\cos(x^2+y^2) \text{ e } \partial_y f(x,y) = 2y\cos(x^2+y^2)\] são contínuas em \(\R^2\), logo \(f\) é diferenciável.
\end{example}

\begin{example}
    A função \(f(x,y) = \begin{cases}
        \frac{x^4}{x^2+y^2},\; (x,y)\neq(0,0) \\
        0,\; (x,y)=(0,0)
    \end{cases}\) é diferenciável?

    Para estudarmos a diferenciabilidade de \(f\), basta verificarmos a continuidade das funções \(\frac{\partial f}{\partial x}\) e \(\frac{\partial f}{\partial y}\). Para isso devemos obter tais funções.

    Verifique que \[\frac{\partial f}{\partial x}(x,y) = \begin{cases}
        \frac{2x^5 + 4x^3y^2}{(x^2 + y^2)^2},\; (x,y)\neq(0,0) \\
        0,\; (x,y)=(0,0)
    \end{cases} e \begin{cases}
        \frac{-2x^4y}{(x^2+y^2)^2},\; (x,y)\neq(0,0)\\
        0,\; (x,y)=(0,0)
    \end{cases}.\] Vejamos que \(\frac{\partial f}{\partial x}\) é contínua em \(\R^2\).

    Se \((x,y)\neq(0,0)\), então \(\frac{\partial f}{\partial x}\) é uma função racional, portanto contínua. Agora, se \((x,y)\neq(0,0)\),
        \begin{align*}
            \lim_{(x,y)\to(0,0)} \frac{\partial f}{\partial x}(x,y)
                & = \lim_{(x,y)\to(0,0)} \frac{2x^5 _ 4x^3y^2}{(x^2+y^2)^2} \\
                & = \lim_{(x,y)\to(0,0)} \left[ 2x\frac{x^4}{(x^2+y^2)^2} + 4x\frac{x^2y^2}{(x^2+y^2)^2} \right] = 0.
        \end{align*}
    De fato, \(\frac{x^4}{(x^2+y^2)^2}\) é limitada para todo \((x,y)\neq(0,0)\) dado que \[0\leq x^2 \leq x^2+y^2 \Rightarrow 0 \leq x^4 \leq (x^2+y^2)^2 \Rightarrow 0 \leq \frac{x^4}{(x^2+y^2)^2} \leq 1.\] Assim como \(\frac{x^2y^2}{(x^2+y^2)^2}\) pois \(0\leq x^2 \leq x^2+y^2\) e \(0\leq y^2 \leq x^2+y^2\) implicam que \[0 \leq x^2 y^2 \leq (x^2+y^2)^2 \Rightarrow 0 \leq \frac{x^2y^2}{(x^2+y^2)^2} \leq 1.\] Do anterior concluímos que \[\lim_{(x,y)\to(0,0)} \frac{\partial f}{\partial x}(x,y) = 0 = \frac{\partial f}{\partial x}(0,0),\] portanto \(\frac{\partial f}{\partial x}\) é contínua em \((0,0)\).

    De forma análoga, mostramos que \(\frac{\partial f}{\partial y}\) é contínua.

    Segue da continuidade de \(\frac{\partial f}{\partial x}\) e \(\frac{\partial f}{\partial y}\) que \(f\) é contínua.
\end{example}
